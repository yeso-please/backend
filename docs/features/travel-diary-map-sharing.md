# 여행기·사진 지도·공개 범위

## 목적

확정 여행 한 건에 사진과 기록을 묶어 발행하고, 여행의 위치를 내 지도에서 다시 볼 수 있게 한다. 기록은 사용자의 선호를 보완하는 신호가 되며, 사용자는 기본 비공개·친구 공개·링크 공개 중 공개 범위를 직접 선택한다.

## 사용자 흐름

```text
확정 코스 선택 → 사진 여러 장 업로드(초안) → 사진별 촬영 위치·일자 확인/수정
→ 제목·본문 작성 → 공개 범위 선택 → 여행기 발행
→ 내 지도에서 핀 선택 → 여행기·사진 타임라인 열람
→ 친구 공개 또는 링크 공유 → 상대는 읽기만 가능
```

## 핵심 규칙

- 여행기 하나는 사용자 소유의 확정 여행(`course`) 하나에만 연결한다. 한 여행에 여행기는 최대 하나이며 발행 전에는 초안으로 수정·삭제할 수 있다.
- 사진은 여행기당 1~30장, 이미지 형식·용량·악성 파일 검증을 거쳐 저장한다. 원본 파일명·EXIF 전체를 공개하지 않는다.
- 지도 핀은 사진에 포함된 좌표가 아니라 사용자가 확인한 여행기 대표 위치 또는 사진별 선택 위치를 사용한다. 사진 위치는 공개 범위와 별도로 `EXACT|CITY|HIDDEN` 정밀도를 선택한다. 기본값은 `CITY`다.
- 공개 범위는 `PRIVATE`(본인), `FRIENDS`(수락된 친구), `LINK`(만료·폐기 가능한 읽기 전용 링크)다. 친구 관계가 없으면 FRIENDS 공개 여행기는 본인만 볼 수 있다.
- 친구 관계는 양쪽 수락 후에만 성립한다. 친구 요청 수신자는 수락·거절·차단할 수 있으며, 차단하면 상대의 FRIENDS 여행기는 즉시 볼 수 없다.
- 지도 공유는 여행기의 링크 공유와 같은 권한을 사용한다. 별도의 전체 지도 공개 링크는 MVP에서 제공하지 않는다. 따라서 링크를 가진 사람도 해당 여행기 핀·내용만 볼 수 있다.
- 발행 후 본문·사진·공개 범위는 변경 가능하지만, 취향 반영은 발행 당시의 검증된 신호만 누적한다. 사진 GPS·자유 본문을 임베딩 입력이나 로그에 넣지 않는다.

## 취향 반영

발행된 여행기에서만 다음의 명시적·검증 가능한 신호를 프로필에 반영한다.

- 연결 여행의 지역과 실제 확정 관광지 카테고리
- 사용자가 선택한 만족 태그(예: `자연`, `역사`, `카페`, `휴식`) 최대 5개
- 선택적 1~5 만족도

본문, 얼굴/이미지 분석, 사진 EXIF, 링크 방문·열람 수는 취향 신호로 쓰지 않는다. 여행기 신호는 온보딩보다 낮은 가중치로 합산하며, 사용자가 여행기를 비공개로 바꿔도 본인 추천에는 유지한다. 취향 반영 자체를 원하지 않으면 발행 시 `includeInTasteProfile=false`를 선택한다.

## 비목표

댓글·좋아요·팔로우·공개 피드 추천·타인의 사진 재사용·공동 편집·친구의 여행기 수정은 MVP 범위 밖이다.
