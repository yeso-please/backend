# 예외 처리

모든 커스텀 예외는 `RuntimeException`을 상속하는 도메인별 베이스 예외를 거칩니다.

```text
RuntimeException
├── AuthException
├── TripException
├── AttractionException
└── ProfileException
```

구체적인 예외의 메시지는 생성자에서 확정합니다.

```java
public class TripNotFoundException extends TripException {
    public TripNotFoundException(Long tripId) {
        super("여행 계획을 찾을 수 없습니다: " + tripId);
    }
}
```

`shared.exception.GlobalExceptionHandler`가 다음 예외를 공통 응답으로 변환합니다.

- 도메인 예외
- `MethodArgumentNotValidException`
- JSON 파싱 실패
- 파라미터 타입 변환 실패
- 지원하지 않는 HTTP 메서드
- 처리하지 못한 예외

예상하지 못한 예외는 내부 메시지를 노출하지 않고 `error` 레벨로 전체 스택 트레이스를 기록합니다. 비즈니스 예외는 예상된 흐름이므로 `warn`으로 기록합니다.

Security 필터에서 발생하는 인증·인가 예외는 ControllerAdvice가 처리하지 못하므로 `AuthenticationEntryPoint`와 `AccessDeniedHandler`가 동일한 에러 형식을 직접 반환합니다.
