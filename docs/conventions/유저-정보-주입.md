# 사용자 정보 주입

새 기능은 Controller에서 인증 사용자를 받고 Service에는 필요한 `userId`만 전달합니다.

```java
@PostMapping
public ResponseEntity<TripResponse> create(
        @CurrentUser CustomUserDetails user,
        @Valid @RequestBody CreateTripRequest request) {
    return ResponseEntity.status(HttpStatus.CREATED)
            .body(tripService.createTrip(user.userId(), request));
}
```

Service가 `SecurityContextHolder`나 `SecurityUtils`를 직접 호출하지 않습니다. 메서드 시그니처만 보아도 인증 사용자 정보가 필요한지 알 수 있어야 합니다.

기존 메서드의 시그니처를 당장 바꾸기 어려운 경우에만 `SecurityUtils`를 예외적으로 사용합니다.
