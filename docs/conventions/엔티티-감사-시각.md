# 엔티티 감사 시각

생성·수정 시각은 클라이언트 입력이나 `LocalDateTime.now()` 필드 초기값으로 채우지 않는다. `JpaAuditingConfig`와 `AuditingEntityListener`가 영속 직전에 서버 시각을 기록한다.

- `created_at`과 `updated_at`을 모두 가진 엔티티는 `shared.persistence.BaseTimeEntity`를 상속한다.
- 생성 시각만 가진 엔티티는 `@CreatedDate`를, 수정 시각만 가진 엔티티는 `@LastModifiedDate`를 기존 컬럼에 붙인다.
- `createdAt`은 `updatable = false`로 유지한다.
- DB 기본값은 외부 적재·직접 SQL 경로의 안전망이고, JPA 경로의 값은 Auditing이 책임진다.

감사 주체(createdBy/updatedBy)는 아직 MVP 범위가 아니다. 추가할 때는 인증 사용자 resolver와 별도 `AuditorAware` 계약을 함께 설계한다.
