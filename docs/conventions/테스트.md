# 테스트

| 종류 | 이름 | 목적 |
|---|---|---|
| 단위 테스트 | `*Test` | DB 없이 도메인·서비스 로직 검증 |
| 통합 테스트 | `*IntegrationTest` | API, Security, DB를 포함한 흐름 검증 |
| 구조 테스트 | `ArchitectureTest` | 패키지 의존성 규칙 검증 |

통합 테스트는 기능별로 `@Nested`로 묶습니다.

```java
@SpringBootTest
@AutoConfigureMockMvc
class TripIntegrationTest {
    @Nested
    @DisplayName("여행 생성")
    class CreateTrip {
        @Test
        @DisplayName("유효한 요청이면 201 Created")
        void createTrip_success() {
        }
    }
}
```

메서드 이름은 `{대상}_{시나리오}` 형식의 영어로 작성하고, `@DisplayName`에는 기대 결과를 한국어로 적습니다. 통합 테스트는 테스트 간 데이터가 남지 않도록 관계 순서를 고려해 정리합니다.
