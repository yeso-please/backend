## 추천: 카카오맵 REST 경로 조회

1. **키·계정을 새로 만들 필요가 없다.** 식당 검색(5-6)에 쓰는 카카오 REST 키와 같은 앱에서 "카카오맵" 사용 설정만 켜면 된다.
2. **응답이 지도 선 그리기에 충분하다.** 경로 좌표가 있어 5-7처럼 `path`로 그릴 수 있고, 대중교통은 환승·요금도 준다.
3. **호출 수가 한도 안이다.** 하루 코스의 구간은 보통 5~8개다. 5-7과 같은 구간 캐시(24시간)를 쓰면 같은 코스를 여러 명이 열어도 다시 부르지 않는다. 일 1,000건이면 하루 약 120~200개 코스(도보·대중교통 각각)를 처음 여는 정도다. 넘으면 10원/건이고, 넘을 때는 지금처럼 직선 추정으로 대체한다.

주의: 무료 한도는 **개발자 계정에서 처음 활성화한 앱에만** 준다. 팀 계정의 어느 앱이 첫 번째인지 확인해야 한다.

## 사람이 고르면 하는 구현

- `KakaoMobilityClient`처럼 `KakaoRouteClient`(도보·대중교통) 인터페이스와 HTTP 구현, 테스트용 가짜 클라이언트.
- 5-7 `GET /courses/{tripId}/routes`에 `transport=WALK|PUBLIC_TRANSIT`이면 그 API로 구간을 받는다(지금은 `CAR`만 도로).
- 코스 항목의 `travelFromPrevious.walkMinutes`·`transitMinutes`도 5-7이 기억해 둔 값이 있으면 그 값을 쓰고 `walkSource`·`transitSource: ROUTE`를 붙인다(자동차와 같은 방식). 편집 응답에서는 새로 부르지 않는다.
- 한도 초과(`-10`)·실패·지연이면 직선 추정 + `estimated: true`. 키는 서버 설정에만 둔다.
