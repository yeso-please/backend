# 시군구(250개) 대표 사진 출처 조사 (T14, D13-1)

- 작성: 2026-10-16. 결정 전 보고서다. **사람이 승인한 뒤 적재한다.**
- 현재 상태: 지역 카드(7-2) `heroImage`는 ① 승인된 지역 소개(`region_contents`)의 검증된 사진 → ② 대표 관광지(추천코스 지점 빈도 순)의 검증된 TourAPI 사진 → ③ 없음. 개발 RDS에 `region_contents`가 0건이라 지금은 모든 지역이 ②로 나온다(관광지 사진이라 "지역 풍경"이 아닐 수 있다).

## 추천안

1. **관광사진 정보 API로 시군구 이름(예: "강릉", "영양군")을 검색해 후보를 3~5장 모은다.** 제목·촬영지에 시군구명이 들어간 것만 남기고, 안내판·클로즈업은 사람이 걸러야 한다(같은 API를 쓴 프로젝트들도 키워드 결과가 들쭉날쭉해 수동으로 골랐다).
2. 후보를 `region_contents`처럼 **승인 흐름**에 태운다: 새 테이블(예: `region_hero_photos`: `region_id`, `image_url`, `title`, `photographer`, `source_name`(한국관광공사), `license`(공공누리 1유형), `status` DRAFT/APPROVED, `reviewed_by`)에 DRAFT로 저장하고 CSV로 검수한다(#89 한 줄 소개와 같은 도구).
3. 지역 카드 규칙에 넣는다: ① 승인된 지역 소개 사진 → **② 승인된 지역 대표 사진(새)** → ③ 대표 관광지 사진 → ④ 없음. 화면에는 `sourceName`·촬영자·이용 조건을 표시한다.

## 막힌 것

- 지금 `.env`의 TourAPI 키로 관광사진 API를 부르면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`다. 공공데이터포털에서 **"한국관광공사_관광사진 정보_GW" 활용신청**이 필요하다(개발 계정은 자동 승인). 신청 뒤 250개 지역 커버 수를 측정해 보고한다.
